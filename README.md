# 专注一下

一个安静的专注计时网站，支持电脑和手机。

## 使用

```sh
node server.cjs
```

访问 http://localhost:4173/ 。构建运行 `node build.cjs`，静态文件输出到 dist。

## 功能

- 专注、短休息、长休息，自定义时长、暂停、重置、刷新恢复和沉浸模式
- 邮箱密码注册与登录，账号独立的日、周、月、年学习记录与统计
- 七天免重复登录；数据库核验会话有效期，退出或到期后拒绝旧令牌访问
- 任务清单、50 句每日文案、换句和收藏
- 六套主题配色、流线背景、计时光效、图表交互和减少动态效果支持
- 独立的完成铃声、音量与震动开关，提供试听和测试；无环境音

未完成任务、计时设置、收藏及提醒偏好保存在当前设备并按账号隔离；完成的学习事件同步至账号。浏览器关闭、后台或锁屏时不能保证声音或震动提醒。

## 数据与账号

使用 Supabase Auth 和 Postgres。前端仅包含公开 publishable key，数据由 RLS 和服务器会话校验隔离；不会暴露管理密钥。密码由认证服务处理。当前注册不要求邮箱验证。

邮件找回功能由 config.js 的 emailEnabled 控制，仅在 SMTP、发信域名和回调地址配置并测试通过后启用。

## 部署

导入此仓库到 Vercel，使用仓库中的 vercel.json。构建只发布明确列出的客户端文件，无依赖安装步骤。部署后的账号服务使用同一个 Supabase 项目。
