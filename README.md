# 专注一下

一个安静的专注计时网站，支持电脑和手机。

## 使用

```sh
node server.cjs
```

访问 http://localhost:4173/ 。构建运行 `node build.cjs`，静态文件输出到 dist。

## 功能

- 专注、短休息、长休息，自定义时长、暂停、重置、刷新恢复和沉浸模式
- 邮箱密码注册与登录，账号独立的日、周、月、年学习记录与统计
- 七天免重复登录；数据库核验会话有效期，退出或到期后拒绝旧令牌访问
- 带确认的任务清单、180 句每日文案、未读优先换句和收藏
- 六套主题配色、流线背景、计时光效、图表交互和减少动态效果支持
- 独立的完成铃声、音量与震动开关，提供试听和测试；无环境音

未完成任务与当前倒计时保存在设备上；登录后，计时时长、配色、提醒开关和音量按设置项同步，已读句子、收藏及完成的学习事件同步至账号。访客数据仅保存在当前浏览器。每天保持当天选中的一句，手动换句优先未读；全部读完后提示，选择重看才开启下一轮。浏览器关闭、后台或锁屏时不能保证声音或震动提醒。

- 放松页面链接到用户指定的两款外部游戏，单独打开
- 添加到主屏幕提供独立安装引导：支持安装的浏览器调用系统弹窗，其他浏览器显示安卓、苹果、电脑的操作步骤；取消或失败也有明确提示。离线时可使用已缓存的基础页面；登录和跨设备同步需要联网
- 铃声音量支持 10%–100%

## 数据与账号

使用 Supabase Auth 和 Postgres。前端仅包含公开 publishable key，数据由 RLS 和服务器会话校验隔离；不会暴露管理密钥。密码由认证服务处理。新注册需要验证邮箱中的八位验证码；日常使用邮箱和密码登录。验证码由 Supabase 生成和校验，前端不会自行认定验证成功。

邮件通过 Resend 的已验证域名 mail.zhuanzhu.cloud 发送，SMTP 密钥仅保存在 Supabase。注册验证码和找回密码使用中文模板。邮件找回由 config.js 的 emailEnabled 控制。免费邮件额度与 Supabase 频率限制耗尽时会阻止本次发送，页面提示稍后重试，已注册账号仍可用密码登录。

## 部署

导入此仓库到 Vercel，使用仓库中的 vercel.json。构建只发布明确列出的客户端文件，无依赖安装步骤。部署后的账号服务使用同一个 Supabase 项目。
